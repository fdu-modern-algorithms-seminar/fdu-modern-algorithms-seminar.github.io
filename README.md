# Fudan Modern Algorithms Seminar

It is a seminar on Modern Algorithms, organized under the School of Mathematical Sciences at Fudan University.

Topics include amortized analysis, probabilistic data structures, high-dimensional algorithms, cache-aware algorithms, parallel/GPU algorithms, optimization, online algorithms, fast polynomial algorithms, and quantum computation.

See the [full syllabus](index.html) for details.

This seminar is launched by [Yuhan Chi](https://github.com/Chi-Shan0707).
